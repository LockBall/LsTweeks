Key changes to L's Tweeks, newest version first.


## 00.24.00 - 2026-10-31
- Added ChatCopySghetti: a module that enables opening a popup so a use can copy chat text to the machine clipboard
- copy icons to open interface and manual Ctrl+C
- configurable line count and special text bracket visibility
- Preserves chat message and inline link/name colors in the copy interface.
- The copy window remembers its size and position, minimizes to a title bar, and offers background color/transparency settings through its gear shortcut.
- Preserves intentional line breaks, counts all skipped lines together, and stores no chat history.
